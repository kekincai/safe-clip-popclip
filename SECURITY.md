# Security Policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Do not open a public issue containing real sensitive data. Use GitHub's private vulnerability reporting feature for vulnerabilities in the extension itself.

When reporting a detection gap, replace every real value with a synthetic example that preserves only the relevant structure. Revoke or rotate any real credential that may have been exposed.

## Scope

Safe Clip is a local pattern-based redaction aid. It does not claim to provide anonymization, data-loss prevention enforcement or protection against every secret format. Users must review output before sharing it.
